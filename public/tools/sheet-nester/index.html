Each DXF or DWG file is treated as one part. The largest closed profile is used for collision/nesting; supported geometry is preserved for DXF export.

Select one or more ASCII DXF or binary DWG files from this device or Files. Each file is treated as one part shape.

Local processing: Drawing bytes stay in this browser. DWG decoding runs in a separate Web Worker using a WebAssembly decoder loaded on demand; the drawing itself is never uploaded.
